# Data Model

Core concepts:

- Workspace: logical project boundary.
- Dataset: collection of documents and artifacts.
- Connector: source integration contract.
- ConnectorRun: one connector execution.
- Pipeline: ordered processing steps.
- PipelineRun: one pipeline execution.
- Document: indexable data unit.
- Artifact: generated file or result.
- EmbeddingRecord: vector for a document.
- SearchQuery: text, vector, or hybrid search request.
